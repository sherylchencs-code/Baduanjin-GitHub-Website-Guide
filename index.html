如何使用 GitHub Pages 建立您的網頁

這份八段錦互動網頁是一個「單一 HTML 檔案」的網站，非常適合發佈到 **GitHub Pages** 上！只要按照以下四個簡單步驟，就能獲得一個專屬的網址，分享給朋友一同運動。

1

註冊與準備 GitHub 帳號

前往 GitHub.com 免費註冊一個帳號。如果已有帳號，直接登入即可。

💡 提示： GitHub 提供免費的靜態網頁託管服務，網址格式通常為 https://您的帳號.github.io/專案名稱。
2

建立新的儲存庫 (Repository)

  1. 登入後，點擊右上角的 「+」 按鈕，選擇 New repository。
  2. 在 Repository name 輸入：baduanjin-app（或任意您喜愛的名稱）。
  3. 將隱私權設定勾選為 Public（公開）。
  4. 勾選 Add a README file。
  5. 點擊最下方的 Create repository。
3

上傳專案程式碼

將您目前閱讀的這份 HTML 程式碼儲存為電腦中的 index.html 檔案。

  1. 在剛建立好的 Repository 頁面中，點擊右上方的 Add file ➔ Upload files。
  2. 將電腦中的 index.html 檔案拖曳進去上傳。
  3. 滑到下方，點擊綠色的 Commit changes 按鈕。
4

開啟 GitHub Pages 服務

  1. 點擊 Repository 頁面上方的 Settings（設定）。
  2. 在左側選單找到 Pages。
  3. 在 Build and deployment 區塊下的 Branch，將 None 改選為 main (或 master)，資料夾保持 /(root)。
  4. 點擊 Save。
  5. 等待約 1-3 分鐘後重新整理頁面，上方就會顯示您的網站專屬網址！🎉
